## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/KalyanbabuD/KalyanbabuD.github.io.git
cd KalyanbabuD.github.io

# Install dependencies
flutter pub get

# Run on Chrome
flutter run -d chrome

# Build for Web Production
flutter build web --release --base-href "/"
```
